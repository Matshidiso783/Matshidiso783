## Project Overview
In this project, I worked with the `Wrldlayoffs` dataset and created staging tables to safely clean and prepare data for the analysis. The main steps include:

- Creating staging tables (`layoff_staging1` and 2)
- Removing duplicates
- Correcting and standardizing data formats
- Adding row numbers for easier tracking
- Handling NULL and incorrect values
- Preparing data for further analysis
